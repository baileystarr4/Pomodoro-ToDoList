## Key Features
- Customizable Pomodoro timer  
- Togglable to-do list  
- Optional notifications with familiar Zelda sound effects  
- Portable single `.exe` file - no installation needed

## Getting Started

### Use the Ready-to-Run App (No Python Required)

Download the `PomoToDo-1.0.0.exe` from the [Releases](https://github.com/baileystarr4/Pomodoro-ToDoList/releases) page and double-click to run.

> **Note:**  
> Windows may warn about the app because it’s unsigned. Click **“More Info” → “Run Anyway”** to proceed.

### Run from Source (For Developers)

If you want to run or modify the app yourself, the full Python source code is available in this repository.

### Build the `.exe` Yourself
If you prefer to create the executable yourself using [`auto-py-to-exe`](https://pypi.org/project/auto-py-to-exe/), switch to the [`windows-exe`]() branch.
This branch includes small adjustments to make building with auto-py-to-exe easier.
After cloning that branch, run:
```bash
auto-py-to-exe
```
Then follow the tool’s prompts to generate the standalone `.exe`.

## About This Project
This project combines **productivity tools** with **Python GUI development**. It demonstrates:
- Building a user-friendly desktop application with **Tkinter** and **Pygame** 
- Managing and storing task data using **Pandas**  
- Integrating notifications on Windows with **Winotify**  
- Packaging a Python app as a **standalone .exe** for easy distribution  
- Applying **intermediate Python skills**, including **object-oriented programming (OOP)**
